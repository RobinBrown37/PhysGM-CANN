# PhysGM-CANN 迁移测试结果：GPU / NPU 与 PhysAssets GT

实验日期：2026-10-30。原仓基线：`7722175ba55db54fd430a7d29a4407b8f8ffe6b6`。本报告据 GPU 侧提交的 `repo_submission/docs/GT_GPU_NPU_COMPARISON.md`、`repo_submission/results/GT_COMPARISON_SUMMARY.json` 与本仓 NPU 实测记录汇总。可移植的[机器可读摘要](benchmark_summary.json)随仓提交；原始逐场景结果、Tensor、MP4 与完整 SHA256 清单不在轻量代码仓库中，复核原始数值需另外取得实验结果包。

## 对比设定

| 项目 | 固定条件 |
| --- | --- |
| 官方 checkpoint | SHA256 `b4cdf3418d95f497ea2d7ef30cf8783849c9791142304749d7bdf16af5b80b6e`，严格加载 645 条模型参数 |
| PhysAssets 测试集 | 512 场景，448 train / 64 validation，14 材料类；manifest SHA256 `411cf19146c9417a42c86893bc72b4ac831b61037a08acfc08fd94392a037f31` |
| 视图 | 每场景前 4 张输入、全部 8 张作为静态渲染目标；后 4 张为 held-out 目标 |
| 精度 | 网络 BF16，静态 renderer / MPM / 损失 FP32；GPU 主比较关闭 TF32 |
| GPU | 单张 RTX 4090（显存49,140 MiB），driver 570.133.07，PyTorch 2.3.0+cu121，gsplat 1.4.0，Warp 0.10.1 |
| NPU | 单张 Ascend 910B3，CANN 9.1.0，PyTorch 2.7.1，TorchNPU 2.7.1.post8 |

同一固定测试集分别由 GPU 和 NPU 预测，再对官方静态 RGBA、材料、E、ν 标签计算指标。RGB GT 按 `rgb × alpha + (1 − alpha)` 合成白底；表中 PSNR 为 512 个**场景 PSNR 的算术平均**。E/ν 误差使用原训练归一化量。每场景包含 8 个静态目标视图并不表示原仓固定只输出 8 张图：静态 renderer 可对提供的目标相机逐张渲染，本实验选了 8 张用于公平比较。

原计划中的严格 GPU/NPU 中间张量与像素 allclose 未通过。深层 BF16 网络、推测不同 SDPA/卷积/归约内核是合理的误差来源，但本实验没有逐层归因证据，因此不能将其作为已证实的根因，也不通过放宽原阈值声明数值对齐。GT 指标回答两端的预测对同一标注结果误差十分接近；但无法证明两端的 Gaussian、像素或训练参数逐元素等价。

## M1/M2：512 场景静态质量

M1 每场景接收四张 512² 图像；M2 对同一场景渲染八个 512² 目标视图。下表是**完整图像**与真实物理标签指标。

| 指标 | GPU | NPU | GPU − NPU | 场景配对 95% bootstrap 区间 |
| --- | ---: | ---: | ---: | ---: |
| 平均场景 PSNR，dB | 25.49842 | 25.51918 | −0.02076 | [−0.02844, −0.01341] |
| RGB MSE | 0.00400816 | 0.00399874 | +0.00000942 | [+0.00000319, +0.00001543] |
| Alpha MSE | 0.00760214 | 0.00758250 | +0.00001964 | [+0.00000793, +0.00003132] |
| 材料准确率 | 60.7422% | 60.9375% | −0.1953 百分点 | [−0.9766, +0.3906] 百分点 |
| 归一化 E MAE | 0.954643 | 0.954685 | −0.000042 | [−0.000244, +0.000157] |
| 归一化 ν MAE | 0.453171 | 0.452862 | +0.000309 | [−0.000533, +0.001162] |

区间以场景为重采样单位，10,000 次 bootstrap，seed 1111；它描述固定分层测试集上的配对差异，不代表全 PhysAssets 总体，也不是预注册的等效性证明。RGB MSE 的 GPU/NPU 差额约为 NPU 指标的 0.24%。14 材料分组的 PSNR 差异在 GPU 侧原始报告中逐类给出；总体均值不能代替各材料结论。

完整 NPU 参考包只传输了每场景 8,192 个固定像素索引，因而输入/held-out/前景分组为**固定像素样本估计**，不得当作完整图像分组指标。GT 前景定义为 alpha > 0.01。

| 固定像素分组 | 有效场景 | GPU PSNR | NPU PSNR | GPU − NPU |
| --- | ---: | ---: | ---: | ---: |
| 全部 8 视图 | 512 | 25.6575 | 25.6683 | −0.0108 |
| 4 个输入视图 | 512 | 28.0532 | 28.0291 | +0.0241 |
| 4 个 held-out 视图 | 512 | 24.5792 | 24.6082 | −0.0290 |
| 全视图 GT 前景 | 511 | 19.2598 | 19.3180 | −0.0581 |
| held-out GT 前景 | 510 | 18.3090 | 18.3821 | −0.0730 |

一场景在固定样本中无前景，两场景无 held-out 前景，仅从对应条件行排除。白背景稀释了整图误差；held-out 前景 PSNR 的 GPU−NPU 配对区间为 [−0.1015, −0.0453] dB。

同步预热后、不含解码/主机传输、checkpoint 加载、编译与导出的每场景核心中位时间：

| 模块 | GPU | NPU | NPU/GPU |
| --- | ---: | ---: | ---: |
| M1 四输入网络 | 0.13300 s | 0.15195 s | 1.14× |
| M2 八目标渲染 | 0.02132 s | 0.28786 s | 13.50× |

M2 比较的是 CUDA gsplat 与本仓 CANN renderer 的**整套系统实现**，不是单一硬件算力比；两端的投影、排序与合成实现不同。该速度结果不表示严格像素 allclose 通过。

## M3：相同步数监督训练

两端从同一官方 checkpoint 初始化，DINO 冻结；场景顺序与 LR 序列已核对。256² 完成恰好 100 次有效更新/100 micro-step；512² 完成 1 次有效更新/8 micro-step。验证集为相同 64 场景。只有 NPU 验证聚合值被转移，M3 没有逐场景配对置信区间。

| 验证指标 | 256² GPU / NPU | 512² GPU / NPU |
| --- | ---: | ---: |
| PSNR，dB | 23.6442 / 23.5800 | 18.6003 / 18.8173 |
| RGB L2 loss | 0.005777 / 0.005951 | 0.017660 / 0.017631 |
| Alpha loss | 0.011566 / 0.012066 | 0.039194 / 0.037222 |
| 材料准确率 | 64.06% / 60.94% | 10.94% / 6.25% |
| 归一化 E MSE | 1.0810 / 1.1519 | 1.3829 / 1.3647 |
| 归一化 ν MSE | 0.7212 / 0.6745 | 119.996 / 139.311 |
| 加权验证总损失 | 0.068369 / 0.068968 | 2.11246 / 2.35396 |

| 训练观测 | 256² GPU / NPU | 512² GPU / NPU |
| --- | ---: | ---: |
| 同步有效更新核心时间 | 0.1556 / 0.7114 s，中位 | 4.2403 / 10.0347 s，单次 |
| 设备峰值已分配内存 | 9.472 / 8.526 GB | 13.173 / 13.706 GB |

512² 只有一次更新，易受启动/编译影响；ν 验证 MSE 在该单步后两端均很大，不能据此评估收敛。100 步是短训功能与速度检查，不是完整预训练或论文指标复现。跨设备 loss、梯度和最终权重不要求逐元素一致；本次报告的验收依据是实际标签上的验证结果及训练流程的成功执行。

## M4/M5：动态功能和性能（无动态 GT）

PhysAssets 提供静态 RGBA、相机与物理标签，**没有** Gaussian 参数 GT、MPM 粒子轨迹 GT 或动态视频 GT。下列状态与图像对照只能作为跨实现诊断，不能写成动态物理真实度指标。

- **M4**：两端使用同一 NPU 导出的 219,416 粒子初始状态、100³ 网格、`dt=2e-4`、10,000 子步。GPU Warp 同步求解器 7.030 s，NPU 仿真 384.023 s，约 54.6× 的实现与机器组合差异。最终粒子质量一致；位置对 NPU 的平均绝对差 `2.82e-6`，但最终协方差最大归一化差 `0.156`，因此不能声称完整状态等价。参考包没有 NPU 的第 1/100 步快照，不能验证原计划早期跨设备状态阈值。
- **M5 隔离回放**：GPU 从同一 NPU 50 帧 Gaussian 缓存与相机渲染，不运行网络/MPM。GPU 中位渲染 `0.003545 s/帧`；GPU/NPU RGBA 元素中 98.752% 满足 `rtol=1e-3, atol=2e-4`，严格全元素 allclose 为假。NPU 7.65 s 离线回放包含不同端到端路径，不计算同口径 kernel 速度比。
- **M1→M4→M5 完整 GPU 流程**：固定与运动相机视频均为 50 帧、512×512、25 FPS，首尾可解码且 Gaussian ID 稳定。GPU 选中 213,614 个渲染 Gaussian，NPU 为 213,532；负载略异，不给出受控的整链速度或质量比。

NPU 独立验收还包括 M1/M2/M3 的一阶反向、M4 六材料与边界的小场景检查、M5 同相机在线/离线回放；最终回归为 121 passed。M4/M5 没有反向迁移验收。真实双 NPU HCCL 与 910C 仍需单独实机验证。
